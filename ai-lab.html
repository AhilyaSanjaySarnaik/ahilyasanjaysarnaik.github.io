Principles

How I approach it

Enforce outside the model

Permissions are checked by code the model can't talk its way past: identity, ABAC and policy-as-code.

Everything untrusted is input

Retrieved text, tool descriptions and tool results are screened like user input, because attackers put payloads there.

Evidence over claims

Repeatable attack test cases, published recall and false-positive rates, and stated limitations.
