    ~/ai-lab/huggingface

    🤗 Auditing Hugging Face models

    Downloading a model can mean running someone else's code. This is the checklist I work through before a model, dataset or Space goes anywhere near production.

    • 🥒
      Pickle files can execute code on load.bin, .pt and .pkl weights use Python's pickle. Prefer safetensors, and scan anything else first.
    • 🧩
      trust_remote_code runs the repo's PythonRead the modelling code before enabling it, or don't enable it.
    • 📌
      Pin a commit, not a branchA pinned revision can't change underneath you after review.
    • 🔍
      Scan before loadingUse picklescan or ModelScan, and check the Hub's own scan results.
    • 🔑
      Spaces leak secretsLook for hard-coded tokens, exposed environment variables and open endpoints.
    • 📜
      Provenance and licenceCheck the model card, training data sources and licence terms.
    # risky: executes code from the repo, tracks a moving branch
model = AutoModel.from_pretrained(
    "org/model",
    trust_remote_code=True)

# safer: pinned commit, safetensors only
model = AutoModel.from_pretrained(
    "org/model",
    revision="<commit-sha>",
    use_safetensors=True)

# plain PyTorch checkpoints: refuse arbitrary objects
state = torch.load("weights.pt", weights_only=True)
